01 / FIXED REVIEW CAPACITY

A finite queue makes the tradeoff visible.

Choose the same capacity for all three models. A queue ranks clients by calibrated default probability, then source ID for exact score ties. It describes observed concentration, without assuming that a review prevents default.

All three remain visible in the comparisons.

Exact queue size = floor(capacity × 6,001).

One unit per nondefault client flagged. Used in section 02, independently of queue capacity.
